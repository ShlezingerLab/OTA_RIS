# WIP 14-10: Why operator-matching (`H ≈ W`) fails for a unit-modulus RIS

**Date:** 2025-10-14
**Setup:** `mnist`, `--teacher thin`, `--inter linear`, `n_t=16`, `n_r=8`,
`--channel_type geometric_rayleigh`, `--snr 40`, `--n_m 256` unless noted.
Teacher (`H = W`) accuracy ≈ **92–94%**. All numbers below are from live runs
this session (`~/.conda/envs/py310/bin/python`, checkpoint
`framework/models/mnist_thin_linear_nt16_nr8__epochs500.pt`).

---

## 0. The question

`cifar_minimal_dnn.py --phi_spectral` picks the RIS phase `phi` by minimizing
the **operator** error `‖W − H_eq‖₂` (`H_eq = H₂ diag(phi) H₁`), independent of
the signal `s`. The default optimizer (`_optimize_phi_agc_mse`) instead matches
the **signal** `H_eq s ≈ W s` per image. The spectral path gives **bad**
accuracy, the default gives **teacher-level** accuracy. Why?

Starting intuition (correct, and ultimately vindicated):
> *If `H` is close enough to `W`, then `Hs` must be close to `Ws`, hence good
> accuracy.*

The intuition is a **theorem** (§3). It fails here only because its
**hypothesis is unreachable** under `|phi_k| = 1` (§4–§6).

---

## 1. The two optimizers, head to head

`n_m=256`, batch of channels, `‖W‖₂ = 5.88`, `‖W‖_F = 10.69`:

| optimizer | `‖H−W‖₂` | matrix cos(H,W) | **signal cos(Hs,Ws)** | accuracy |
|---|---|---|---|---|
| `--phi_spectral` (operator) | 10.23 | 0.39 | **0.56** | **28.73%** |
| default AGC-MSE (per-image) | 139.99 | 0.22 | **1.0000** | **94.00%** |

Definitions (both scale-invariant, in `[0,1]`, `1` = perfectly aligned):

- **matrix cos** `= |⟨H_eq, W⟩_F| / (‖H_eq‖_F ‖W‖_F)` — operator alignment.
- **signal cos** `= mean_s |⟨Hs, Ws⟩| / (‖Hs‖ ‖Ws‖)` — output-direction alignment.

**Reading:** accuracy tracks **signal cos**, nothing else. The operator-matching
path has the *better* matrix number and the *worse* accuracy. The default path's
`‖H−W‖₂ = 140` is almost entirely **scale** (`‖H_eq‖_F = 216` vs `‖W‖_F = 11`,
~20× too big) — a scale AGC divides straight back out — yet its signal cos is a
perfect `1.0000` because it re-optimizes `phi` per image to a rank-1 target.

So the "anti-correlation of spectral norm with accuracy" is a **metric
artifact**: `‖H−W‖₂` is scale-sensitive and *neither* operator is actually close
to `W` (matrix cos 0.39 and 0.22 are both poor). What matters is signal cos.

---

## 2. Scaling cannot rescue the spectral path

The operator misalignment is **directional** (cos ≈ 0.4–0.5), so no scalar — on
the output or on `W` — can fix it. Tested three scalars (`n_m=256`):

| scaling `c` | `‖cH−W‖₂` | `‖cHs−Ws‖₂` | note |
|---|---|---|---|
| `c = 1` (raw) | 10.23 | 22.87 | — |
| `eta = ⟨H,W⟩_F/‖H‖_F²` (complex) | 5.34 | 13.59 | `|eta|≈0.168`, phase only 6.4° |
| `g = Re⟨H,W⟩_F/‖H‖_F²` (real) | 5.35 | 13.63 | ≈ `eta`; measured **~15%** acc |
| AGC (`‖y‖=‖Ws‖`) | 6.82 | 14.80 | measured **~27%** acc |

**Paradox that makes the point:** `eta`/`g` achieve a *lower* signal error
(13.6) than AGC (14.8) yet decode *worse* (~15% vs ~27%). Reason: a scalar that
minimizes `‖Ws − c·Hs‖` with poor alignment does so by **shrinking** `Hs` to
`‖Ws‖·cosθ ≈ 4.4` (vs `‖Ws‖ ≈ 15.6`). The decoder was trained on vectors of
length `‖Ws‖` and is magnitude-sensitive, so the under-scaled vector fails even
though it is "closer" in L2. AGC deliberately keeps the right magnitude at the
cost of a larger L2 error. Scaling is a dead end; the code reverted to plain
spectral + (optionally) AGC.

Current code (`wireless_forward`): `--phi_spectral` uses the raw operator output
(**AGC disabled** for this path); spectral(no-AGC) = **28.73%**, essentially the
same as spectral+AGC (~27%) — confirming scale is not the lever.

## 3. The theorem (your intuition, proved)

Let `E = H − W`, `a = Ws`, `b = Hs = a + Es`.

**Step A — operator error bounds signal error.**
```
‖Hs − Ws‖ = ‖E s‖ ≤ ‖E‖₂ ‖s‖,   and   ‖Ws‖ ≥ σ_min(W) ‖s‖
⟹  δ_s := ‖Hs−Ws‖/‖Ws‖ ≤ ‖H−W‖₂ / σ_min(W) =: δ_op.
```

**Step B — small relative signal error forces cosine → 1** (law of cosines):
```
cos(Hs,Ws) ≥ 1 − δ_s² / (2(1−δ_s)),      δ_s < 1.
```

**Combined:**
```
‖H−W‖₂ < σ_min(W)  ⟹  cos(Hs,Ws) ≥ 1 − δ_op²/(2(1−δ_op))  →  1.
```

So the chain `H ≈ W ⟹ Hs ≈ Ws ⟹ accuracy` is **valid**. The catch is the bar:
operator error must fall below **`σ_min(W)`** — the *smallest* singular value,
not something small next to `‖W‖`.

**Verification (live).** `W` singular values
`[5.88, 5.20, 4.79, 4.03, 3.54, 0.72, 0.61, 0.43]`, so `σ_min = 0.43`,
`cond ≈ 14`. Spectral `‖H−W‖₂ = 10.23 = 24·σ_min` → precondition violated by
24× (it exceeds even `σ_max = 5.88`), bound vacuous, measured `δ_s = 1.50`,
signal cos `0.56`. Consistent.

---

## 4. The theorem, measured end-to-end

Substitute `H = W + E` (random `E`, controlled `‖E‖₂`) for the operator and run
**real MNIST** through the actual decoder (teacher `H=W` → 92.1%):

| `‖H−W‖₂` | / σ_min | bound cos ≥ | accuracy |
|---|---|---|---|
| 0.043 | 0.10 | 0.994 | 91.9% |
| 0.106 | 0.25 | 0.958 | 91.7% |
| 0.213 | 0.50 | 0.750 | 91.8% |
| 0.426 | 1.0 | — | 91.7% |
| 0.851 | 2.0 | — | 91.1% |
| 1.702 | 4.0 | — | 86.5% |
| **10.21** | **24.0** | — | **27.9%** |

Two conclusions:
1. Drive `‖H−W‖₂` to `≈ σ_min` and accuracy is **~teacher** (91.7%). The
   implication holds and is forgiving (still 86.5% at `4·σ_min`).
2. The last row (`‖H−W‖₂ = 10.21`, what the spectral RIS actually achieves)
   gives **27.9%**, matching the real spectral run (**28.7%**). The whole story
   closes: spectral fails *only* because its operator error is 24× too large.

## 5. Can infinite `N_m` make `‖H−W‖₂` small? (feasible, but unfindable)

`H_eq = Σ_{k=1}^{N_m} phi_k D_k`, `D_k = h₂^{(k)} h₁^{(k)⊤}` rank-1, `|phi_k|=1`.
Two requirements to reach `W`:

1. **Span:** `{D_k}` must span the `n_r×n_t` space — needs `N_m ≥ n_r n_t = 128`
   *and* diverse dyads (Rayleigh ✓; strong LoS ✗, all `D_k` collinear → README §7).
2. **Unit-modulus feasibility:** by Lyapunov convexity the Minkowski sum of
   `N_m` circles fills a solid zonoid whose radius grows `∝ N_m`; since `‖W‖` is
   fixed, `W` lies inside for large `N_m`. So it is **feasible in principle**.

But the **solver** (Adam on phases, from random init) does not find it, and gets
**worse** with `N_m` (`‖H_eq‖_F ∼ √N_m · 11` grows, so the required destructive
cancellation deepens):

| N_m | free-coeff lstsq relF | unit-mod `‖H−W‖₂` |
|---|---|---|
| 64 | 0.73 | 18.9 |
| 128 | **7e-6** | 14.2 |
| 256 | 7e-7 | **4.37** (best) |
| 512 | 7e-7 | 6.79 |
| 1024 | 8e-7 | 14.3 |
| 2048 | 1e-6 | 27.3 |
| 4096 | 2e-6 | 53.4 |

With **free complex** coefficients the error hits `1e-6` at `N_m ≥ 128` (span is
there). With **unit-modulus** it never drops below `σ_min` and degrades past
`N_m=256`. The unit-modulus solution *exists* (Lyapunov) but lives in a
vanishingly small basin — the free solution needs magnitudes `|c_k| ∈
[2e-4, 4e-2]`, wildly non-uniform, which `|phi_k|=1` forbids. This is a
**findability** wall, not (for large `N_m`) a feasibility wall. More elements
add scale to cancel, not usable DOF.

(`s`-covariance has **effective rank 7.46 / 16**, so "take care of `s`" via
data-weighted single-`phi` matching would still have to match `W` over ~7–8
directions; the maximal way to take care of `s` is per-image matching — which
*is* the default AGC-MSE optimizer, already at signal cos = 1.0.)

---

## 6. The fix: give back per-element magnitude (free coefficients / AirFC)

Drop `|phi_k|=1`, allow free complex `c_k` (least-squares to `W`), single
channel, `n_m=256`, real MNIST:

| operator | `‖H−W‖₂` | / σ_min | accuracy |
|---|---|---|---|
| unit-modulus `|phi|=1` | 4.21 | 9.9 | 63–66% |
| **free complex `c_k`** (magnitude DOF) | **4.4e-6** | ~0 | **92%** |
| `H = W` exactly (teacher) | 0 | 0 | 92% |

Removing the single constraint `|phi_k|=1` collapses `‖H−W‖₂` to `≈0` **and**
lifts accuracy to the teacher — same channel, same `N_m`, same decoder. This is
an idealized **AirFC** (`Uᴴ H₂ diag(phi) H₁ P ≈ W`): the `P`/`U` precoders
supply exactly the per-element magnitude DOF that phase-only lacks.

---

## 7. Summary chain (verified end-to-end)

```
magnitude DOF  →  ‖H−W‖₂ ≪ σ_min(W)  →  cos(Hs,Ws) → 1  →  accuracy → teacher
   (removed by |phi|=1)     (the wall)       (§3 theorem)       (§4 measured)
```

- The intuition `H ≈ W ⟹ Hs ≈ Ws ⟹ accuracy` is a **theorem** and is confirmed
  (§3–§4). The bar is `σ_min(W)`.
- Unit-modulus RIS cannot reach that bar: scaling cannot (directional error, §2),
  and more `N_m` cannot with phase-only optimization (findability wall, §5).
- The missing ingredient is **per-element magnitude control**; restoring it
  (free `c_k` / AirFC) recovers the teacher exactly (§6).
- For **accuracy**, the default per-image `_optimize_phi_agc_mse` is already
  optimal (signal cos = 1.0, 94%). Operator-matching (`--phi_spectral`) is the
  wrong objective for a unit-modulus device.
