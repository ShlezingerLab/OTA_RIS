# WIP 14-10: Operator-matching (`H ≈ W`) for a unit-modulus RIS — why the spectral objective fails and the right one works

**Date:** 2025-10-14
**TL;DR:** The `--phi_spectral` operator path gives bad accuracy (~29%) not because
a unit-modulus RIS can't match `W`, but because the *spectral-norm objective with
no scale freedom* is the wrong formulation. With one global complex scale `η` and a
Frobenius objective (`--phi_frob`), a single `s`-free unit-modulus `φ` reaches the
teacher (93.96%). §5–§6 correct the earlier "unit-modulus wall" conclusion.

**Setup:** `mnist`, `--teacher thin`, `--inter linear`, `n_t=16`, `n_r=8`,
`--channel_type geometric_rayleigh`, `--snr 40`, `--n_m 256` unless noted.
Teacher (`H = W`) accuracy ≈ **92–94%**. All numbers below are from live runs
this session (`~/.conda/envs/py310/bin/python`, checkpoint
`framework/models/mnist_thin_linear_nt16_nr8__epochs500.pt`).

---

## 0. The question

`cifar_minimal_dnn.py --phi_spectral` picks the RIS phase `phi` by minimizing
the **operator** error `‖W − H_eq‖₂` (`H_eq = H₂ diag(phi) H₁`), independent of
the signal `s`. The default optimizer (`_optimize_phi_agc_mse`) instead matches
the **signal** `H_eq s ≈ W s` per image. The spectral path gives **bad**
accuracy, the default gives **teacher-level** accuracy. Why?

Starting intuition (correct, and ultimately vindicated):
> *If `H` is close enough to `W`, then `Hs` must be close to `Ws`, hence good
> accuracy.*

The intuition is a **theorem** (§3), with bar `‖H−W‖₂ < σ_min(W)`. The *spectral*
objective can't reach that bar (§1–§4) — but that's a property of the **objective**,
not of `|phi_k|=1`. §5–§6 show the right `s`-free objective (Frobenius + a global
scale `η`) *does* reach it with one unit-modulus `φ`, recovering teacher accuracy.

---

## 1. The two optimizers, head to head

`n_m=256`, batch of channels, `‖W‖₂ = 5.88`, `‖W‖_F = 10.69`:

| optimizer | `‖H−W‖₂` | matrix cos(H,W) | **signal cos(Hs,Ws)** | accuracy |
|---|---|---|---|---|
| `--phi_spectral` (operator) | 10.23 | 0.39 | **0.56** | **28.73%** |
| default AGC-MSE (per-image) | 139.99 | 0.22 | **1.0000** | **94.00%** |

Definitions (both scale-invariant, in `[0,1]`, `1` = perfectly aligned):

- **matrix cos** `= |⟨H_eq, W⟩_F| / (‖H_eq‖_F ‖W‖_F)` — operator alignment.
- **signal cos** `= mean_s |⟨Hs, Ws⟩| / (‖Hs‖ ‖Ws‖)` — output-direction alignment.

**Reading:** accuracy tracks **signal cos**, nothing else. The operator-matching
path has the *better* matrix number and the *worse* accuracy. The default path's
`‖H−W‖₂ = 140` is almost entirely **scale** (`‖H_eq‖_F = 216` vs `‖W‖_F = 11`,
~20× too big) — a scale AGC divides straight back out — yet its signal cos is a
perfect `1.0000` because it re-optimizes `phi` per image to a rank-1 target.

So the "anti-correlation of spectral norm with accuracy" is a **metric
artifact**: `‖H−W‖₂` is scale-sensitive and *neither* operator is actually close
to `W` (matrix cos 0.39 and 0.22 are both poor). What matters is signal cos.

## 2. Scaling cannot rescue the spectral path

The operator misalignment is **directional** (cos ≈ 0.4–0.5), so no scalar — on
the output or on `W` — can fix it. Tested three scalars (`n_m=256`):

| scaling `c` | `‖cH−W‖₂` | `‖cHs−Ws‖₂` | note |
|---|---|---|---|
| `c = 1` (raw) | 10.23 | 22.87 | — |
| `eta = ⟨H,W⟩_F/‖H‖_F²` (complex) | 5.34 | 13.59 | `|eta|≈0.168`, phase only 6.4° |
| `g = Re⟨H,W⟩_F/‖H‖_F²` (real) | 5.35 | 13.63 | ≈ `eta`; measured **~15%** acc |
| AGC (`‖y‖=‖Ws‖`) | 6.82 | 14.80 | measured **~27%** acc |

**Paradox that makes the point:** `eta`/`g` achieve a *lower* signal error
(13.6) than AGC (14.8) yet decode *worse* (~15% vs ~27%). Reason: a scalar that
minimizes `‖Ws − c·Hs‖` with poor alignment does so by **shrinking** `Hs` to
`‖Ws‖·cosθ ≈ 4.4` (vs `‖Ws‖ ≈ 15.6`). The decoder was trained on vectors of
length `‖Ws‖` and is magnitude-sensitive, so the under-scaled vector fails even
though it is "closer" in L2. AGC deliberately keeps the right magnitude at the
cost of a larger L2 error. Scaling is a dead end; the code reverted to plain
spectral + (optionally) AGC.

Current code (`wireless_forward`): `--phi_spectral` uses the raw operator output
(**AGC disabled** for this path); spectral(no-AGC) = **28.73%**, essentially the
same as spectral+AGC (~27%) — confirming scale is not the lever.

## 3. The theorem (your intuition, proved)

Let `E = H − W`, `a = Ws`, `b = Hs = a + Es`.

**Step A — operator error bounds signal error.**
```
‖Hs − Ws‖ = ‖E s‖ ≤ ‖E‖₂ ‖s‖,   and   ‖Ws‖ ≥ σ_min(W) ‖s‖
⟹  δ_s := ‖Hs−Ws‖/‖Ws‖ ≤ ‖H−W‖₂ / σ_min(W) =: δ_op.
```

**Step B — small relative signal error forces cosine → 1** (law of cosines):
```
cos(Hs,Ws) ≥ 1 − δ_s² / (2(1−δ_s)),      δ_s < 1.
```

**Combined:**
```
‖H−W‖₂ < σ_min(W)  ⟹  cos(Hs,Ws) ≥ 1 − δ_op²/(2(1−δ_op))  →  1.
```

So the chain `H ≈ W ⟹ Hs ≈ Ws ⟹ accuracy` is **valid**. The catch is the bar:
operator error must fall below **`σ_min(W)`** — the *smallest* singular value,
not something small next to `‖W‖`.

**Verification (live).** `W` singular values
`[5.88, 5.20, 4.79, 4.03, 3.54, 0.72, 0.61, 0.43]`, so `σ_min = 0.43`,
`cond ≈ 14`. Spectral `‖H−W‖₂ = 10.23 = 24·σ_min` → precondition violated by
24× (it exceeds even `σ_max = 5.88`), bound vacuous, measured `δ_s = 1.50`,
signal cos `0.56`. Consistent.

## 4. The theorem, measured end-to-end

Substitute `H = W + E` (random `E`, controlled `‖E‖₂`) for the operator and run
**real MNIST** through the actual decoder (teacher `H=W` → 92.1%):

| `‖H−W‖₂` | / σ_min | bound cos ≥ | accuracy |
|---|---|---|---|
| 0.043 | 0.10 | 0.994 | 91.9% |
| 0.106 | 0.25 | 0.958 | 91.7% |
| 0.213 | 0.50 | 0.750 | 91.8% |
| 0.426 | 1.0 | — | 91.7% |
| 0.851 | 2.0 | — | 91.1% |
| 1.702 | 4.0 | — | 86.5% |
| **10.21** | **24.0** | — | **27.9%** |

Two conclusions:
1. Drive `‖H−W‖₂` to `≈ σ_min` and accuracy is **~teacher** (91.7%). The
   implication holds and is forgiving (still 86.5% at `4·σ_min`).
2. The last row (`‖H−W‖₂ = 10.21`, what the spectral RIS actually achieves)
   gives **27.9%**, matching the real spectral run (**28.7%**). The whole story
   closes: spectral fails *only* because its operator error is 24× too large.

## 5. One `s`-free `φ` CAN reach the teacher — it was a formulation bug, not a wall

> **Correction.** An earlier draft of this section concluded that a unit-modulus
> RIS "cannot" reach the `σ_min(W)` bar with one `φ` (a "findability wall", with
> more `N_m` making it worse), and that the fix required per-element magnitude DOF
> (AirFC). **That was wrong** — an artifact of the *spectral-norm objective with no
> scale freedom*. With the right `s`-free objective, a unit-modulus `φ` reaches the
> teacher. (Credit: the data-weighted-Frobenius idea came from a colleague's note;
> the measurements below are what we found testing it.)

`H_eq = Σ_{k=1}^{N_m} phi_k D_k`, `D_k = h₂^{(k)} h₁^{(k)⊤}` rank-1, `|phi_k|=1`.
Span still requires `N_m ≳ n_r n_t = 128` with diverse dyads (Rayleigh ✓; strong
LoS ✗ → README §7). The real question is the **objective**. Compare three `s`-free
objectives (one `φ`, no per-image adaptation), each optionally with a single
**global complex scale `η`** folded in (`min_η ‖W − η H_eq‖`), `n_m=256`:

| objective | relF(·, W) | `‖·−W‖₂` | / σ_min |
|---|---|---|---|
| spectral, no η | 0.575 | 3.39 | 8.0 |
| spectral **+ η** | 0.079 | 0.459 | 1.08 |
| Frobenius, no η | 0.095 | 0.649 | 1.53 |
| **Frobenius + η** | **0.014** | **0.080** | **0.19** |

**The dominant fix is the global scale `η`, not the norm.** Adding one `η` to the
*spectral* objective already collapses `8·σ_min → 1.08·σ_min`; switching to
Frobenius then clears the bar comfortably (`0.19·σ_min`, i.e. `‖ηH−W‖₂ < σ_min`).
By the §3 theorem that must give teacher accuracy — and it does (§6).

Why `η` matters and the old "magnitude DOF" claim was a red herring: with global
`η`, the effective coefficients are `η·φ_k`, all of equal magnitude `|η|`. For
`N_m > n_r n_t = 128` the system `η H_eq = W` is **underdetermined**
(≈`N_m` phase DOF + `η` vs `2·n_r n_t` real equations), so it has *near-uniform-
magnitude* solutions reachable by `η·(unit-modulus)`. The free-LSTSQ solution's
wildly non-uniform magnitudes `|c_k| ∈ [2e-4, 4e-2]` are just *one* (particular)
solution, not the only one — matching `W` never actually required them.

**`N_m` scaling now goes the right way** (Frobenius+η, relF of `ηH` vs `W`, mean
over channels):

| N_m | relF(ηH, W) | `‖ηH−W‖₂` / σ_min | real cos(ηHs, Ws) |
|---|---|---|---|
| 128 | 0.55–0.59 | ~8 | 0.76–0.83 |
| 256 | **0.013** | **0.19** | **0.9999** |
| 512 | 0.005–0.009 | 0.07–0.14 | 1.0000 |

More `N_m` makes it **better** (opposite of the spectral solver), because more
elements give the under-determined system more slack to find a uniform-magnitude
match. The earlier "degrades past `N_m=256`" table was the η-less spectral solver
and does not reflect feasibility.

## 6. Live results: teacher accuracy from one `s`-free `φ` (`--phi_frob`)

Implemented as a flag: `--phi_frob` minimizes `min_η ‖W − η H_eq‖_F` (uniform);
`--phi_weighted` weights it by `Σ_s^{1/2}`. The `frob` path applies its own global
`η` (no per-image AGC — fully `s`-free). Real pipeline, `--snr 40 --n_m 256
--channel_type geometric_rayleigh --data mnist` (teacher ≈ 93.9%):

| wireless phi path | flag | accuracy |
|---|---|---|
| spectral `‖W−H‖₂` | `--phi_spectral` | 28.73% |
| **uniform Frobenius + η** | `--phi_frob` | **93.96%** |
| Σ_s-weighted Frobenius + η | `--phi_weighted` | 84.85% |
| per-image AGC-MSE (default) | (none) | 94.00% |

So **one `s`-free unit-modulus `φ` + one global `η` matches the teacher (93.96%)**,
essentially tying the per-image optimizer — without ever seeing the individual
image. Operator-matching was never the problem; the *spectral* objective and the
*missing scale* were.

**Data-weighting (`Σ_s`) hurts, it does not help.** The intuition "match `W` only
on the ~6–7 data directions" fails because `Σ_s` is full-rank (effective rank
6.3/16, not a hard subspace): down-weighting the off-data directions breaks the
individual images that *do* use them. Uniform Frobenius beats weighted at every
`N_m` (3-channel mean, scratch):

| N_m | uniform-Frob | weighted-Frob |
|---|---|---|
| 96 | 46.7% | 39.5% |
| 128 | 60.3% | 49.5% |
| 160 | 82.5% | 71.5% |
| 192 | 90.9% | 82.4% |
| 256 | 92.1% | 91.8% |

(The "relaxed bar" `σ_min(W|data)` also went the *wrong* way — 0.126 at r=8 vs
full `σ_min=0.43` — because the data occupies some of `W`'s weak directions. But
it doesn't matter: Frobenius+η clears the full `σ_min` bar anyway.)

For completeness, per-element magnitude DOF (free complex `c_k`, i.e. idealized
AirFC) also works and is even tighter (`‖H−W‖₂ ≈ 4e-6`, 92%), but it is **not
required** — one global `η` suffices.

### 6.1 CIFAR (same story, plus a BatchNorm subtlety)

Repeating on `cifar_thin_linear` (teacher ceiling only ≈ **43%** — a thin *linear*
mid is a weak teacher for CIFAR), `--snr 40 --n_m 256`:

| wireless phi path | flag | accuracy |
|---|---|---|
| spectral | `--phi_spectral` | 12.1% |
| **uniform Frobenius + η** | `--phi_frob` | **43.07%** |
| Σ_s-weighted Frobenius + η | `--phi_weighted` | 41.1% |
| per-image AGC-MSE (default) | (none) | 43.07% |

Same ordering as MNIST: `--phi_frob` ties the teacher, spectral fails, weighted is
slightly worse. **But there was a trap:** the CIFAR checkpoint's mid has a
**BatchNorm** (`intermediate(s) = BN(W s)`, `cos(W s, intermediate(s)) = 0.40`),
whereas MNIST's mid is pure `W s`. The operator-matching paths target the pre-BN
complex `W` (via `_complex_W_from_linear`), so without accounting for BN they land
at ~19% even though the *operator* match is fine (relF ≈ 0.012). The fix (now in
`wireless_forward`, matching `airfc_forward`): **re-apply the teacher mid BN
digitally** after the spectral/frob operator synthesis, before decoding. The
per-image/cosine paths need no change — they match `intermediate(s)` with BN already
baked into the target. (Cleanest apples-to-apples is still a `--mid_bn false`
teacher, per `framework/CLAUDE.md`.)

## 6.2 What is `η`? One global real scalar, set from `W` and channel statistics

The frob path computes a per-channel complex `η = ⟨H_eq, W⟩_F / ‖H_eq‖_F²`. How much
does it actually vary across channels, and can it be fixed once?

**Magnitude is nearly constant; phase is a pure gauge.** Over 24 Rayleigh channels
(`n_m=256`):

| quantity | MNIST | CIFAR |
|---|---|---|
| `\|η\|` | mean 0.117, **CV 10%** | mean 0.041, **CV 9.4%** |
| `∠η` | std 100°, spans 302° | std 89°, spans 311° |

The phase scatter is **not** channel variation: each `φ` solve starts from random
init and converges to an arbitrary global phase, and `η`'s phase rotates to cancel
it. Formally it is a U(1) gauge — `(φ·e^{iψ}, η·e^{-iψ})` realizes the identical
operator — so only `|η|` is physical. Copying one *complex* `η` across channels
fails (21%); folding `∠η^{(c)}` into each `φ^{(c)}` and using **one shared real gain**
matches per-channel (91.8% vs 91.85% on MNIST; 41.7% vs 42.65% on CIFAR).

**Closed form.** Because `cos(ηH_eq, W) ≈ 1`, `|η| = ‖W‖_F / ‖H_eq‖_F`, and the
*solved* `‖H_eq‖_F` is a channel/`N_m` constant (≈92 for both datasets, independent
of `W`) ≈ `½√(N_m·E‖D_k‖²)`. Hence `η` is set from `W` and the pool statistics alone:

```
η ≈ 2‖W‖_F / sqrt( N_m · E[ ‖h₂^{(k)}‖² ‖h₁^{(k)}‖² ] )      (a-priori, from W + pool)
  = ‖W‖_F / ⟨‖H_eq‖_F⟩_pool                                  (or measured from solved φ)
```

Verified (set once from `(pool, W)`, applied to all): MNIST a-priori 0.118 → 91.80%,
measured 0.116 → 91.45%. Structurally `|η| ∝ ‖W‖_F` (the only `W`-dependence; 0.117
vs 0.041 is exactly `‖W‖_F` 10.69 vs 3.70), shrinking with channel power and `√N_m`.
The factor `≈½` (solver coherent-cancellation gain) was identical at `n_m=256` for
both datasets; treat it as an empirical constant for this regime, not yet swept over
`N_m`. **Requirement:** solve each `φ` for a real-positive `W`-alignment (fold `∠η`
into `φ`) so the single shared scalar is valid.

**Head-to-head verification — fully `s`-free vs the `s`-aware default.** The frob
controller never touches `s` (`φ` from `(W, H₁, H₂)`, `η` the constant above,
phase gauge-fixed from the operator), yet it matches the default per-image AGC-MSE
optimizer that adapts `φ` to every image (`--snr 40 --n_m 256`, 50-channel pool):

| dataset | teacher | default AGC-MSE (**uses `s`**) | const-η frob (**`s`-free**) | η |
|---|---|---|---|---|
| MNIST | 91.95% | 92.20% | **91.95%** | 0.1184 |
| CIFAR | 42.20% | 42.15% | **41.20%** | 0.0409 |

MNIST is identical (within channel noise); CIFAR matches within ~1% (the `|η|`
~9% spread + BN), still at the teacher ceiling. So a controller that never sees
`s` — operator-matched `φ` plus one constant gain set from `W` and the channel-pool
statistics — realizes `W` as well as the per-image optimizer that adapts to each
input.

## 6.3 Training `W` so `η → 1` (no receiver gain)

Since `|η| = ‖W‖_F / ‖H_eq‖_F` and `‖H_eq‖_F ≈ τ := ½√(N_m·E‖D_k‖²)` is a fixed
pool constant (≈90 here), training the teacher with `‖W_lin‖_F = τ` makes `|η| → 1`:
the RIS realizes `H_eq ≈ W` directly and the receiver needs **no gain**, with the
decoder **co-trained** at that scale (not rescaled after the fact as in the §6.2
gauge trick). Implemented in `train()` behind `wnorm_tau`/`wnorm_mode`:

- **hard** — project `W_c` onto the `‖·‖_F = τ` sphere after every optimizer step.
- **soft** — add `λ·((‖W_c‖−τ)/τ)²` to the loss.

**Results** (500 epochs, `--teacher thin --inter linear`, `geometric_rayleigh`,
`--snr 40 --n_m 256`, `τ=90.15`; unconstrained teacher ≈ 91.95% MNIST / 42.20%
CIFAR):

| dataset | mode | ‖W‖_F | teacher | \|η\| (CV) | acc(computed η) | **acc(η≡1, no gain)** |
|---|---|---|---|---|---|---|
| MNIST | hard | 90.15 | 91.75% | 0.996 (7.7%) | 91.60% | **91.65%** |
| MNIST | soft | 90.15 | 91.55% | 0.974 (8.4%) | 91.55% | **91.60%** |
| CIFAR | hard | 90.15 | 42.35% | 0.972 (9.9%) | 42.60% | **42.40%** |
| CIFAR | soft | 90.15 | 42.65% | 0.976 (7.5%) | 42.80% | **42.00%** |

All four hit `‖W‖_F = τ`, `|η| ≈ 1`, teacher accuracy unchanged vs unconstrained,
and **`η≡1` (no receiver gain) ties the teacher** on both datasets. Notes:

- **It's a scale gauge, so accuracy is unchanged** — the point is removing the
  receiver gain, not raising accuracy (as expected).
- **Hard is the clean method.** Soft *does* reach `τ` by 500 epochs but needs a
  large `λ` (=10000) and is slow: at 5 epochs it stalled at `‖W‖≈12` because **Adam
  normalizes the penalty gradient** (adaptive step caps the pull toward a large
  target norm); it only crawls to `τ` over hundreds of epochs. Hard projection
  reaches `τ` immediately and exactly.
- **Fixed-regime caveat** (unchanged from §6.2): `τ ∝ √(N_m · channel power)`, so
  `η≈1` holds only at the trained operating point; change `N_m`/path loss and `η`
  drifts — a fixed `W` can't track per-deployment channel power.
- Residual `|η|` CV ≈ 8–10% ⇒ one fixed gain costs ~1%; a light power-AGC (or the
  per-channel `|η|`) mops up the last bit.

## 7. Summary chain (verified end-to-end)

```
right s-free objective  →  ‖ηH−W‖₂ < σ_min(W)  →  cos(Hs,Ws) → 1  →  accuracy → teacher
 (Frobenius + global η)        (§5, cleared)         (§3 theorem)        (§6, 93.96%)
```

- The intuition `H ≈ W ⟹ Hs ≈ Ws ⟹ accuracy` is a **theorem**, confirmed §3–§4.
  The bar is `σ_min(W)`.
- The spectral path (`--phi_spectral`) fails **only** because of its objective: the
  worst-case (spectral) norm with no scale freedom, stuck at `~8–24·σ_min` (§1, §4).
- **One global scale `η` + a Frobenius objective clears the bar** with a single
  `s`-free unit-modulus `φ` → teacher accuracy (`--phi_frob`, 93.96%, §5–§6). This
  overturns the earlier "unit-modulus wall / need per-element magnitude" conclusion.
- Data-weighting (`--phi_weighted`) *hurts* here (full-rank `Σ_s`), §6.
- Scaling *alone* (a post-hoc scalar on the spectral output) still cannot help — it
  fixes magnitude, not the directional error (§2). The win is choosing `η` *inside*
  the operator objective, so `φ` itself is optimized for the scaled match.
- The per-image default `_optimize_phi_agc_mse` remains optimal and simplest for
  accuracy (signal cos = 1.0, 94%); `--phi_frob` is the `s`-free operator-level
  route that now also works.
